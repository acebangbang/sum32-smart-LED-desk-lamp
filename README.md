# sum32-smart-LED-desk-lamp
Smart desk lamp on RT-Thread: encoder for on/off &amp; brightness; menu for color temp (3000–6500K) with dual PWM; BH1750 auto‑dimming to 500 lux; real‑time lux display; OLED with home/menu &amp; 15s auto‑off; timer (10s–120min/off); memory save; pop‑ups for lux deviation (300–700) &amp; 45‑min rest (filtered, deferred). All functions run during screen‑off.
